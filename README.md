# 📚 Estudos de Java - Lógica de Programação

Repositório com exercícios desenvolvidos durante meus estudos em Java, com foco em lógica de programação.

## 💻 Conteúdos praticados

* Estruturas de decisão (`if`, `else`, `switch`)
* Laços de repetição (`for`, `while`, `do while`)
* Métodos com e sem retorno
* Arrays (vetores)
* Entrada de dados com `Scanner`
* Validações e controle de fluxo

---

## 📂 Projetos incluídos

### 🔐 Login

Sistema simples de cadastro e login com:

* Validação de usuário e senha
* Controle de tentativas
* Bloqueio após 3 erros

---

### 👨‍🎓 Alunos

Cadastro de alunos com:

* Nome e nota
* Cálculo da média da turma
* Identificação da maior e menor nota

---

### 🔢 Análise de Números

Programa que:

* Lê vários números inteiros
* Calcula soma total
* Identifica maior e menor valor
* Conta números pares e ímpares

---

### 🏦 Banco

Sistema de caixa eletrônico simples com:

* Menu interativo (`switch`)
* Ver saldo
* Depósito
* Saque com validação
* Controle de saldo

---
